# Pokédex Project
A fun Python-based Pokédex tool that calculates type effectiveness and displays results in a styled layout.
## Planned Features
- Update user inputs so that name or number can be searched (currently number only)
- Make the tool viewable in HTML, with only user inputs and output displayed (code hidden)
- Dual-type logic with real damage multipliers to give all types which the Pokémon is "strong versus" and "weak versus" 
- Pokédex-style visual output
- Stats chart showing Pokémon's stats vs max and average
- 🌐 Interactive web interface to display outputs based on user-input Pokémon number: hides code, showcases clean results; ideal for sharing
